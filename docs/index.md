# Parallel Image Reader

**KiraAI 并行识图插件** — 并发识别图片内容，大幅降低多图场景回复延迟。

::: tip 解决的问题
KiraAI 原生按顺序处理图片：N 张图 = N 次串行调用。多图场景下延迟叠加严重。
本插件将其改造为并发调用，延迟从 `sum(t_i)` 降低为 `max(t_i)`。
:::

::: info 三种加载模式
通过 `load_mode` 切换：
- **懒加载（默认）** — 触发时才识图，被忽略的消息零消耗
- **乐观加载** — 收到即后台识图，更低延迟但消耗更多
- **LLM 选择性加载** — 只放标识符，LLM 按需调工具识图，最省 VLM
:::

## 特性

- **并发识图** — 多张图片同时识别，延迟从串行降为并行
- **零历史污染** — 图片描述以纯文字形式写入记录，不残留任何标记
- **零浪费** — 被忽略的消息不调识别，不烧额度
- **缓存复用** — 相同图片再次出现秒回，无需重复识别
- **超时降级** — 单张图超时自动跳过，不影响其他图片和回复
- **质量调节** — 可选压缩后送识别，减小上传体积
- **三模式切换** — 懒加载 / 乐观加载 / LLM 选择性加载，运行时换态无缝

## 快速开始

```bash
pip install -r requirements.txt
```

将插件目录复制到 KiraAI `data/plugins/` 下，在 WebUI 中启用即可。
