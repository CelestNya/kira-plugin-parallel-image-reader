# 渲染样式对照 — 原生 vs 插件（v2.4.2）

> 所有输出均来自真实 `message_format_to_text`（KiraAI 核心）实跑，
> 复现：`../KiraAI-src/.venv/Scripts/python.exe tests/render_styles.py`
> 输入结构为真实 MessageChain 树；`[时间] 昵称: ` 前缀是 napcat 适配器为转发节点注入的。
> 图片描述"集成测试图片描述"来自测试 VLM（真实 VLM 会输出实际内容）。

## 全局差异（一句话）

| | 图片渲染 | 嵌套转发 |
|---|---|---|
| **原生** | `[Image 描述, file_path: data/temp\xxx.jpg]` | **1 层完整，≥2 层内容全部消失（无痕）** |
| **插件** | `[Image #2cd8bde4: 描述]`（短 id 可追溯） | 按 `forward_max_depth` 展开（默认 64），超限深层无痕省略 |

---

## S1 单转发单节点（最简）

```
输入结构:
Forward
  Text([2026-08-06 10:00:00] 张三: 看看这张图)
  Image

原生: [Forward [2026-08-06 10:00:00] 张三: 看看这张图[Image 集成测试图片描述, file_path: data/temp\a15fddc8.jpg]]
插件: [Forward [2026-08-06 10:00:00] 张三: 看看这张图[Image #2cd8bde4: 集成测试图片描述]]
```
差异：仅图片格式（原生带文件路径，插件带短 id）。外层 `[Forward ...]` 包裹一致。

## S2 单转发三节点（真实聊天记录）

```
输入结构:
Forward
  Text([时间] 张三: 第一张图) + Image
  Text([时间] 张三: 这是文字消息)
  Text([时间] 张三: 第二张图) + Image

原生: [Forward [2026-08-06 10:00:00] 张三: 第一张图[Image ...jpg]

[2026-08-06 10:00:00] 张三: 这是文字消息

[2026-08-06 10:00:00] 张三: 第二张图[Image ...jpg]]
插件: [Forward [2026-08-06 10:00:00] 张三: 第一张图[Image #2cd8bde4: 集成测试图片描述]

[2026-08-06 10:00:00] 张三: 这是文字消息

[2026-08-06 10:00:00] 张三: 第二张图[Image #2cd8bde4: 集成测试图片描述]]
```
要点：**节点间用空行分隔**（核心渲染行为）；每节点自带昵称前缀。多图、纯文本节点顺序保留。

## S3 两层嵌套（转发里套转发）

```
输入结构:
Forward
  Text([时间] 张三: 外层第一条) + Image
  Text([时间] 张三: 外层第二条转发下面：)
  Forward                    ← 内层转发
    Text([时间] 张三: 内层消息)
    Image

原生: [Forward [2026-08-06 10:00:00] 张三: 外层第一条[Image ...jpg]

[2026-08-06 10:00:00] 张三: 外层第二条转发下面：]
     ↑ 内层转发的全部内容（"内层消息"和图片）消失，无任何痕迹

插件: [Forward [2026-08-06 10:00:00] 张三: 外层第一条[Image #2cd8bde4: 集成测试图片描述]

[2026-08-06 10:00:00] 张三: 外层第二条转发下面：[2026-08-06 10:00:00] 张三: 内层消息[Image #2cd8bde4: 集成测试图片描述]]
     ↑ 内层内容展开进外层，层级边界靠昵称前缀区分（无嵌套标记）
```

## S4 三层嵌套

```
输入结构:
Forward
  Text([时间] 张三: L1)
  Forward
    Text([时间] 张三: L2)
    Forward
      Text([时间] 张三: L3 最深层) + Image

原生: [Forward [2026-08-06 10:00:00] 张三: L1]
     ↑ L2、L3 全消失

插件: [Forward [2026-08-06 10:00:00] 张三: L1[2026-08-06 10:00:00] 张三: L2[2026-08-06 10:00:00] 张三: L3 最深层[Image #2cd8bde4: 集成测试图片描述]]
     ↑ 全部展开，图在最深层也能识别
```

## S5 Reply 里是转发

```
输入结构:
Text(引用了一条转发：)
Reply(id=r1)
  Forward
    Text([时间] 张三: 被引用的转发) + Image

原生: 引用了一条转发：[Reply ID: r1 content: [Forward [2026-08-06 10:00:00] 张三: 被引用的转发[Image ...jpg]]]
插件: 引用了一条转发：[Reply ID: r1 content: [2026-08-06 10:00:00] 张三: 被引用的转发[Image #2cd8bde4: 集成测试图片描述]]
     ↑ 注意：插件版 Reply 内容里的 [Forward ...] 包裹消失（拍平展开），
       只留昵称前缀。Reply 内容内的转发不再有转发壳标记。
```

## S6 转发节点里是 Reply

```
输入结构:
Forward
  Text([时间] 张三: 他回复了：)
  Reply(id=r1)
    Text(原消息) + Image

原生: [Forward [2026-08-06 10:00:00] 张三: 他回复了：[Reply ID: r1 content: 原消息[Image ...jpg]]]
插件: [Forward [2026-08-06 10:00:00] 张三: 他回复了：[Reply ID: r1 content: 原消息[Image #2cd8bde4: 集成测试图片描述]]]
差异：仅图片格式。Reply 壳保留（与 S5 的 Forward 壳消失形成对比）。
```

## S7 成环（恶意构造）

```
输入结构:
Forward
  Text(环1) + Image
  Forward
    Text(环2)
    Forward
      ↺ (环)

原生: [Forward 环1[Image ...jpg]]            ← 环2 及更深被过滤
插件: [Forward 环1[Image #2cd8bde4: 集成测试图片描述]环2]
     ↑ 环内的图和环2 文本保住了；环本身被截断（无崩溃）
```

## S8 深度隔断（forward_max_depth=4，16 层纯转发链）

```
输入结构: Forward→Forward→…→16 层 → 最深层 Text+Image

原生: [Forward ]                                  ← 空壳（第 2 层起全过滤）
插件: [Forward ]                                  ← 空壳（展开 4 层后深层仍被核心过滤）
```

**⚠️ 这就是需要你拍板的样式问题**：隔断/深层省略后渲染成**空 `[Forward ]`**——
LLM 看到空转发，完全不知道里面有内容被省略。可选方案见下方。

---

## 样式要点总结

1. **转发壳**：最外层 `[Forward ...]` 包裹；嵌套转发展开后**没有层级标记**，靠 napcat 的 `[时间] 昵称: ` 前缀区分节点
2. **Reply 壳**：`[Reply ID: xxx content: ...]` 保留；Reply 内的 Forward 壳会被拍平（S5）
3. **节点分隔**：空行（核心行为）
4. **图片格式**：插件版 `[Image #id: 描述]`，id 可被 LLM 用于 `describe_image` 工具
5. **隔断样式（待定）**：当前空壳 `[Forward ]` 无省略提示
